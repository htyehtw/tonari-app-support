# The Girl Next Door (Tonari) — iOS Support

Support information for the iOS game **The Girl Next Door / 隔壁的她**.

- [Privacy policy (English, 繁體中文, 简体中文, 日本語, 한국어, Tiếng Việt)](PRIVACY_POLICY.md)
- [Report a problem or ask for support](https://github.com/htyehtw/tonari-app-support/issues)

## Before reporting a problem

Please include the app version, device model, iOS version, and a short description of what happened. GitHub Issues are public. Do not post passwords, verification codes, private contact details, or screenshots/save files that contain information you do not want public. GitHub handles issue content and account information under its [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
